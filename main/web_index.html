配置管理


config.json 位于TF卡根目录：屏幕或本页修改参数都会自动写入，每次覆盖自动备份 config.json.bak。WiFi名称/密码与透传开关经文件加载后在下次启动生效。





















日志存储


存储占用率达到阈值后，记录仪按通道独立删除各自目录下最早的日志文件，绝不跨通道删除；占用回落到阈值以下即停止清理。























固件升级 OTA


固件先上传到TF卡暂存，校验通过后安装到备用分区并重启。新固件启动后有30秒健康确认窗口，超时未确认或主动回滚都会退回旧版本；断电时可从上一次成功槽位继续启动。
